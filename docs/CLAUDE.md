# FFFlow fork documentation

This directory contains development roadmaps for the Yaunder fork. The plugin's authoritative design remains in `plugin/docs/architecture.md`.

- `roadmap/skill-evals/roadmap.md` describes the proposed evaluation program.
- `roadmap/skill-evals/harness.md` describes real GitHub fixtures and offline grading of Claude Code session logs.
- Its `phases/` describe delivery scope and acceptance criteria; `scenarios/` define the initial regression cases.
- Proposed behavior must be identified as proposed. Do not describe planned runners or eval results as implemented or measured.
- Durable rationale belongs here. Transient planning state belongs in `/tmp/ffflow-plans/`; captured work items belong in the tracker or `docs/tasks/`.
